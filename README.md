### Description
ISI-Market est une plateforme web permettant aux étudiants
du Groupe ISI de déposer, consulter, filtrer et rechercher
des petites annonces (livres, matériel informatique, services
d'entraide académique).

### Technologies utilisées
- **Front-end** : HTML, CSS, JavaScript
- **Données** : localStorage, MySQL
- **Scripting** : Python (analyse et export)
- **Utilitaire** : Langage C (tri et recherche)
- **Versionnement** : Git / GitHub

### Structure du projet
ISI-Market/
├── web/          # Pages HTML, CSS, JavaScript
├── scripts/      # Script Python (analyse.py)
├── utilitaire/   # Utilitaire C (utilitaire.c)
├── sql/          # Schéma, données de test, requêtes
├── data/         # Fichiers JSON exportés
└── docs/         # Journal IA, documentation
